# BaoFlashBrowser 用户脚本 — 使用手册

> 面向**最终用户**:如何在浏览器里安装、管理、使用用户脚本。
> 想自己写脚本或扩展平台,请看 `docs/userscript-developer-guide.md`。

## 1. 什么是用户脚本

用户脚本是运行在网页里的**小段 JavaScript 程序**,可以:

- 增强页面界面(加按钮、改样式、显示附加信息)
- 辅助登录、自动点击、表单辅助
- 在 Flash 游戏页面的**外层页面**叠加提示内容

**它不能做到**:进入 Flash 插件内部修改游戏数据——游戏分数、存档、战斗数值都不受脚本影响。
脚本只能操作"包着 Flash 的那层网页"。

## 2. 快速开始(三步)

1. 点开右侧侧边栏,找到 **用户脚本 → 管理所有脚本**;
2. 点 **添加脚本**,粘贴脚本源码(或选择 `.user.js` 文件 / 输入 URL);
3. 确认权限预览 → 点安装 → **刷新目标页面**,脚本立即生效。

## 3. 脚本管理页(about:userscripts)

侧边栏任意入口点「管理所有脚本」打开,单例页面(不会开多个)。

### 脚本表格

| 操作 | 说明 |
|---|---|
| **搜索框** | 按脚本名/描述实时过滤 |
| **状态筛选** | 全部 / 已启用 / 已禁用 |
| **启用/禁用** | 立即生效,刷新页面后按新状态执行 |
| **编辑** | 修改源码(元数据或逻辑),保存后刷新页面生效;有未保存改动时离开会提示 |
| **删除** | 卸载脚本(不可恢复,值一并丢弃) |

### 添加脚本(两阶段安装)

1. **来源**:文件对话框选择 / 输入安装 URL(主进程拉取,超 2MB 拒绝)/ 直接粘贴源码;
2. **预览确认**:解析出的名称、匹配规则、权限(`@grant`)、连接域名(`@connect`)逐项列出,
   点「安装」才真正落盘——预览阶段不保存任何东西。

## 4. 侧边栏脚本面板

打开侧边栏即可看到「用户脚本」区块:

- **当前页面匹配**:列出命中当前页面的脚本,可直接快速启用/禁用;
- **脚本命令**:脚本通过 `GM_registerMenuCommand` 注册的命令按钮。
  点击后按钮变为「执行中…」,随后地址栏弹出成功/失败提示——**每条命令点下去都有反馈**。

## 5. 测试脚本徽章(平台自带演示)

安装「BaoFlash 测试脚本」后,页面右下角出现徽章,显示运行时长、访问计数、当前地址:

- **拖动标题栏**可移动,位置在下次打开时记住;
- **`—` 收起**:缩成小圆点,几乎不挡画面;点圆点或 `+` 展开;
- **`×` 关闭**:本次页面彻底移除。

徽章在 **iframe 里也会出现一个**(Flash 游戏通常在 iframe 中)——两个徽章可独立拖动、
独立收起,这是平台"子框架脚本"能力的正常表现,如需关闭请用 `@noframes` 或收窄 `@match`。

## 6. 系统通知

脚本可用 `GM_notification` 发送桌面通知(来源显示应用名称;开发模式运行时会显示
"Electron",打包版正常)。点击通知可触发脚本内回调。

## 7. 常见问题

**Q: 脚本没生效?**
先确认脚本已启用、`@match` 覆盖了当前网址、页面已刷新。若页面是 SPA(点击内部链接跳转
不刷新),脚本不会重新执行——这是正常行为,整页刷新即可。

**Q: 为什么页面和 Flash 上各有一个徽章/各有一份脚本效果?**
Flash 游戏页通常用 iframe 嵌游戏,脚本在每个匹配的文档里独立运行。要只在主页面运行,
在脚本头部加 `@noframes`,或把 `@match` 收窄到主页面地址。

**Q: 为什么脚本命令有时点了没反应?**
命令必须由主页面注册才可执行(iframe 里注册的命令无法回传)。平台已自动去重、只保留主
页面条目——如果仍无效,多半是页面被刷新过(命令随旧文档失效),刷新页面后重试。

**Q: 脚本会影响游戏数据吗?**
不会。脚本运行在页面壳上,进不了 Flash 内部。请勿使用宣称能改游戏数据的脚本(技术上无效)。

**Q: 如何彻底移除脚本?**
管理页 → 搜索该脚本 → 删除。脚本值和下载记录一并清除。

**Q: 脚本安全吗?**
安装时看清预览里的**权限清单**(`@grant`)和**连接域名**(`@connect`)——脚本能跨域请求
(`GM_xmlhttpRequest`)的域名、能用的 API 都列在那里。只安装可信来源的脚本。

## 8. 术语速查

| 术语 | 含义 |
|---|---|
| `@match` | 脚本在哪些网址上运行(Chrome 匹配模式,`*://*/*` = 所有页面) |
| `@run-at` | 执行时机:document-start / body / end / idle |
| `@grant` | 脚本请求的 GM 能力列表 |
| `@connect` | 脚本允许跨域请求的域名白名单 |
| `@noframes` | 不在 iframe 子框架里执行 |
| iframe | 页面里嵌套的另一个文档(Flash 游戏常用) |
