为什么是「页 + 叠加层」而不是二选一

  • 设置页负责长内容：主题卡片、引擎说明、后续的下载位置/清理/关于。空间够，能像 Edge 一样长下去，也能被 Ctrl+Tab / 标签栏正常管理。
  • 叠加层负责把三个最常改的项放在鼠标旁：主题、默认引擎、语言。它直接复用 M1 已验收的叠加层（焦点、Esc、失焦关闭、窗口缩放假制）。
  • 同步：两者都只是投影，写入走同一个设置单例；任一处改动 → 落库 → nativeTheme / 广播 → 另一处立刻反映（第三张截图就是这个状态）。
  • 内部页身份：bao://settings 跑在外壳会话、拿不到页面权限，与 http(s) 页面完全隔离；不进历史、不参与引擎切换与站点规则。
