三条事实（可复核，不是凭印象）

问题结论依据
一条书签都没有时，Chrome 的新标签页上有书签栏吗？ 没有 Chromium 142 源码 BookmarkBarController::ShouldShowBookmarkBar()： if (!has_bookmarks && !has_saved_tab_groups) return false;； 实测 Chrome 158 全新 profile 的新标签页也没有（见 evidence-2026-11-26-chrome158-ntp-empty.png）
Edge 呢？ 有，而且带一行提示文案 实测 Edge 158 全新 profile：「若要进行快速访问，请将你的网址收藏在此收藏栏上。立即管理收藏」（见 evidence-2026-11-26-edge158-ntp-empty.png）
「只有新标签页有横条」准确吗？ 默认成立，但有三个补充 ① 用户可开关成「所有标签都显示」（bookmark_bar.show_on_all_tabs，默认 false）； ② 空书签不显示（Chrome）；③ 判定是「前台标签里有新标签页」，不是「当前标签是新标签页」

「文件夹下拉」是什么行为

书签栏上的一个书签项如果指向的是文件夹，它右边会带一个小三角；点它不会导航，而是在条下方弹出一个列表， 列出该文件夹里的项——这就是「下拉」。里层还可以有子文件夹（再套一层下拉）。 代价：横条要处理「点开位置、自动关闭、键盘可达、以及条上的项太多时怎么溢出」。 首版如果不做，条上就只能平铺根层的普通书签，文件夹只能在面板里展开。
