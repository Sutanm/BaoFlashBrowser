# 多窗口验收清单（P8 · 手工项）

对应计划书 [multi-window-plan.md](multi-window-plan.md) §8.3。自动化门禁已全部通过，本清单只列**必须真人/真机**确认的行为。

## 0. 前置

```bash
# 自动化门禁（应全绿）
npm run typecheck
npm test -- --run
npm run test:electron
npm run test:e2e
npm run test:smokes
npm run probe:deep:batched   # 47/51 会各自拉起子进程，分批跑更稳
```

启动应用：`npm start`（或打包产物）。每个手工项完成后把 `[ ]` 改成 `[x]`，并在备注写出实际结果。

| # | 步骤 | 期望 | 结果 |

| 大文件/长时间 Flash 播放 | 环境依赖 | 手工第 9 项 |
