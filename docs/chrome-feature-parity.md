# Chrome 功能对照清单（BaoFlashBrowser 1.1.2）

> 用途：把 Chrome 用户能感知的功能逐项对照，标出现状与依据，作为 1.1.3 及后续版本的选型依据。
> 口径：以 **1.1.2 源码**为准（2026-11-10 按代码检索整理），**未逐项运行时验证**；标 ❓ 的必须
> 用 `npm run probe` / 手工操作确认后才能排期。源码与本文冲突时以源码为准。
>
> 版本语义（项目约定）：
> - `1.1.x`：**大补丁级**功能包，可包含具体功能；小修补攒着发，不单独发包。
> - `1.x.0`：**架构级**变更（如 1.0.1 → 1.1.0 由 webview 换 BrowserView，正式确认为浏览器项目）。
> - `1.2.0`：**双内核**（Chromium 87 保 Flash + 最新 Electron 用现代特性）等里程碑级突破。
> - `2.0.0`：**产品定位**变更——放弃 Flash，转向通用浏览器。
