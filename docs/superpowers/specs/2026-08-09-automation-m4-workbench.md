# 自动化 M4：主程序工作台

## 页面结构

M4 使用两个互补入口：

- `about:automation`：脚本库、Blockly 积木编辑器、JSON 代码编辑、校验、保存与 `.baoauto` 导出。
- 网页侧栏“自动化”：选择已导入脚本、检查就绪、立即启动、3 秒倒计时启动和停止。

执行入口必须位于网页侧栏。内部工作台页面没有 BrowserView，如果从该页面启动，截图区域会失去真实网页尺寸。

## 脚本库

主进程把已安装脚本持久化到 `userData/automation/packages/<脚本 ID>.baoauto`。启动时会重新扫描并校验这些包；写入使用临时文件和备份文件替换，异常中断后会优先恢复备份。Renderer 只能通过系统文件选择器导入、导出或选择素材目录，不能提交任意文件路径。编辑后的工作流会再次执行 Zod 校验和素材引用完整性校验，导出时保留原素材。

目前支持：

- 导入、查看和切换脚本包；重复 ID 会询问是否替换。
- 新建空脚本、复制和删除脚本。
- 递归导入素材目录，并在脚本库中查看素材清单。
- 将工作流还原为积木。
- 编辑并保存积木。
- 在积木与 JSON 代码之间切换。
- JSON 校验后同步回积木。
- 导出更新后的 `.baoauto`。

单个包安装后的素材总量限制为 60MB。所有文件名和包 ID 都继续经过现有 `.baoauto` 路径安全规则校验。

## 运行反馈

网页侧栏订阅主进程状态，显示空闲、检查、就绪、倒计时、执行、完成、失败和取消状态。执行期间同时显示已完成步数与当前步骤摘要，例如“第 2 步 · 点击图片 buttons/start.png”，方便用户确认脚本没有卡住。

## 性能边界

Blockly 通过动态 import 按需加载。普通浏览首包约 611KB；约 742KB 的工作台代码块只会在首次打开 `about:automation` 时读取。

## 验证

`npm run probe:automation-m4` 会构建 renderer，然后验证：

- `about:automation` 能通过 `file://` 动态加载。
- 脚本库和导入工作流正常显示。
- 新建、复制、删除和素材清单入口存在。
- 六个彩色分类和导入积木正常渲染。
- JSON 编辑入口存在。
- 网页侧栏包含检查就绪、立即启动、倒计时启动、停止控制和当前步骤反馈。

持久化服务的单元测试还会验证：新建、修改、导入素材、复制、进程重启后恢复，以及删除后的磁盘清理。

素材缩略图与当前网页识别测试已在 [M5 调试设计](./2026-08-09-automation-m5-debugging.md) 中继续实现。
