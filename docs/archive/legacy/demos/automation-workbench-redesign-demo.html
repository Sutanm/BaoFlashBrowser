bao.ocr.readNumber

读取指定区域中的数字，返回可直接参与计算的 number。区域坐标可以使用可粘贴的 x,y 字符串。

bao.ocr.readNumber(region: Region): Promise<number>

参数

字段类型说明
from"x,y"区域左上角相对坐标
to"x,y"区域右下角相对坐标

示例

const price = await bao.ocr.readNumber({
from: "1200,1800", to: "4200,2800"
});
